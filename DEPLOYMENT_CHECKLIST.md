# 🚀 AI Job Saver Deployment Checklist

This guide ensures a smooth deployment of the AI Job Saver project to Render.

## 🛠️ Backend Deployment (Render Web Service)

### 1. Create Web Service on Render
- **Root Directory**: `backend`
- **Build Command**: `npm install`
- **Start Command**: `npm start`
- **Runtime**: `Node 22`

### 2. Environment Variables
Add the following variables in the Render Dashboard:

| Variable | Description | Source |
| :--- | :--- | :--- |
| `PORT` | Server port (default: 5000) | Render Default |
| `SUPABASE_URL` | Your Supabase Project URL | Supabase Dashboard |
| `SUPABASE_KEY` | Your Supabase Service Role Key | Supabase Dashboard |
| `GROQ_API_KEY` | Your Groq API Key for Llama 3 | Groq Console |
| `JWT_SECRET` | A strong random string for JWT signing | Generated by you |
| `NODE_VERSION` | `22` | Render Env Var |

### 3. Verification
- [ ] Backend health check: Visit `https://your-app.onrender.com/` (Should see "Job Saver API Running")
- [ ] Test Authentication: Log in via the extension.
- [ ] Test Extraction: Save a job and verify it appears in Supabase and Google Sheets.
- [ ] Test Export: Download the Excel file and verify content.

## 🧩 Extension Deployment (Local/Store)

### 1. Build Extension
```bash
cd extension
npm install
npm run build
```

### 2. Configure API URL
Ensure the `.env` file in the `extension` directory (or Render build environment) has:
`VITE_API_URL=https://your-app.onrender.com`

### 3. Load into Chrome
- Open `chrome://extensions`
- Enable **Developer Mode**.
- Click **Load unpacked** and select the `extension/dist` folder.

## 🗄️ Database Setup
- [ ] Execute `database/schema.sql` in the Supabase SQL Editor.
- [ ] Verify the `idx_jobs_user_id` index was created.
